# Social previews

The layouts in this folder were rendered at 1200 × 630 to the versioned PNGs in `public/social/`. Re-render them with the same viewport after any artwork changes. `src/components/SocialMeta.astro` provides the shared Open Graph and Twitter metadata; Dance Africa supplies its own image and alt text.

The homepage and its URL fragments share the House of Ray image. Share `/dance-africa/` to show the event-specific image.
